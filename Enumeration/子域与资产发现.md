# 子域与资产发现

## 用途 / 适用场景

对目标域名做资产测绘：收集子域名、识别存活站点、探测技术栈、抓取 URL 与历史 URL、批量漏洞扫描。用于渗透测试前期的攻击面扩大与信息收集。

## 关键命令

### 子域名枚举

```bash
# subfinder 被动收集子域
subfinder -d <DOMAIN> -o subs.txt

# 配合 API 更快（配置 provider-config.yaml）
subfinder -d <DOMAIN> -all -o subs.txt

# amass 被动枚举
amass enum -passive -d <DOMAIN>

# amass 被动 + 保存
amass enum -passive -d <DOMAIN> -o amass.txt

# assetfinder 仅输出子域
assetfinder --subs-only <DOMAIN>
assetfinder --subs-only <DOMAIN> >> subs.txt
```

### 存活探测

```bash
# httpx 批量探测存活，输出状态码/标题/技术栈
httpx -l subs.txt -sc -title -tech-detect -o live.txt

# 只看 200/301/302/403
httpx -l subs.txt -sc -title -tech-detect -mc 200,301,302,403 -o live.txt

# 指定端口 + 跟随重定向
httpx -l subs.txt -sc -title -ports 80,443,8080,8443 -follow-redirects
```

### 漏洞扫描

```bash
# nuclei 扫描存活目标（默认模板）
nuclei -l live.txt -o vulns.txt

# 指定模板
nuclei -l live.txt -t <TEMPLATES> -o vulns.txt

# 指定模板目录 + 严重度过滤
nuclei -l live.txt -t http/cves/ -severity critical,high -o vulns.txt
```

### 爬虫与 URL 收集

```bash
# katana 爬虫抓 URL
katana -u <URL> -o urls.txt

# katana 带 JS 解析 + 深度
katana -u <URL> -jc -d 5 -o urls.txt

# gau 收集历史 URL
gau <DOMAIN>
gau <DOMAIN> -o gau.txt

# waybackurls 收集历史 URL
waybackurls <DOMAIN>
waybackurls <DOMAIN> | tee wayback.txt
```

### 技术栈识别

```bash
# whatweb
whatweb <URL>
whatweb <URL> -a 3

# wappalyzer（浏览器插件，或 CLI）
wappalyzer <URL>
```

## 参数说明

| 工具 | 参数 | 说明 |
| --- | --- | --- |
| subfinder | `-d` | 目标域名 |
| subfinder | `-all` | 使用全部数据源 |
| subfinder | `-o` | 输出文件 |
| amass | `enum -passive` | 被动枚举模式 |
| assetfinder | `--subs-only` | 只输出子域名（不带 IP） |
| httpx | `-l` | 输入文件 |
| httpx | `-sc` | 输出状态码 |
| httpx | `-title` | 输出标题 |
| httpx | `-tech-detect` | 技术栈探测 |
| httpx | `-mc` | 匹配状态码 |
| nuclei | `-l` | 输入目标文件 |
| nuclei | `-t` | 指定模板 |
| nuclei | `-severity` | 严重度过滤 |
| katana | `-u` | 目标 URL |
| katana | `-jc` | 抓取 JS 文件并解析 |
| katana | `-d` | 爬取深度 |
| whatweb | `-a` | 激进程度（1-4） |

## 实战流程

```bash
# 1. 收集子域
subfinder -d <DOMAIN> -all -o subs.txt
amass enum -passive -d <DOMAIN> >> subs.txt
assetfinder --subs-only <DOMAIN> >> subs.txt
sort -u subs.txt -o subs.txt

# 2. 存活探测 + 技术栈
httpx -l subs.txt -sc -title -tech-detect -o live.txt

# 3. 对存活目标抓 URL
katana -list live.txt -jc -d 3 -o urls.txt
gau <DOMAIN> >> urls.txt
waybackurls <DOMAIN> >> urls.txt

# 4. 批量漏洞扫描
nuclei -l live.txt -severity critical,high -o vulns.txt

# 5. 手工确认技术栈
whatweb $(head -1 live.txt)
```

## 常见坑

- **subfinder 不配 API 数据少**：默认无 API 时结果少，配好 `provider-config.yaml` 里各数据源 key 后结果翻倍。
- **amass 慢**：`enum` 全量很慢，先 `-passive`，必要时再 `-active`；结果交叉验证。
- **httpx 漏端口**：默认只扫 80/443，非标端口用 `-ports` 指定。
- **nuclei 误报/噪音**：默认全模板噪音大，先按 `-severity` 或指定 `-t` 收窄；对目标做授权确认后再扫。
- **历史 URL 可能失效**：gau/waybackurls 拿到的是历史快照，逐个访问验证存活。
- **katana 需 headless**：要渲染 JS 用 `-js-crawl`，需要 Chromium/Chrome 环境。
